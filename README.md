# Super Platformer

Браузерная 2D-платформенная игра. Работает на телефонах, планшетах и компьютерах.

## Управление
- Телефон: экранные кнопки внизу.
- Компьютер: A/D или стрелки для движения, W/↑/Пробел для прыжка.

## Публикация
GitHub Actions публикует содержимое корня репозитория в GitHub Pages после изменений в ветке `main`.
